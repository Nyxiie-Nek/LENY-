1º. Lista de Requisitos Funcionais
O sistema deve cadastrar e manter os dados pessoais dos alunos.

O sistema deve cadastrar e manter os cursos ofertados pela escola.

O sistema deve cadastrar e manter os dados dos professores.

O sistema deve cadastrar e manter as disciplinas associadas a cada curso.

O sistema deve permitir a matrícula dos alunos nos cursos.

2º. Entidades
As entidades principais são:

Aluno

Curso

Disciplina

Professor


3º. Atributos de Cada Entidade

Aluno: ID_Aluno, Nome, CPF (ou RG/Data de Nascimento), Telefone, E-mail.

Curso: ID_Curso, Nome_do_Curso, Carga_Horaria.

Disciplina: ID_Disciplina, Nome_da_Disciplina, Carga_Horaria.

Professor: ID_Professor, Nome, CPF, Formacao, E-mail.

4º. Relacionamentos entre as Entidades


Aluno está matriculado em Curso (1 Aluno pode estar em 1 ou mais Cursos; 1 Curso tem N Alunos).

Curso possui Disciplinas (1 Curso tem várias Disciplinas; 1 Disciplina pode pertencer a cursos diferentes).

Professor leciona Disciplina (1 Professor pode ministrar N Disciplinas).
